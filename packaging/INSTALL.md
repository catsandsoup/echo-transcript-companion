# Install Echo Transcript Companion

1. Unzip the release and keep the extracted `EchoTranscriptCompanion` folder in a permanent location.
2. In Chrome, open Extensions → Manage Extensions and turn on Developer mode.
3. Choose Load unpacked and select the folder containing `manifest.json`.
4. Confirm Assignment Dates — Echo Transcripts is enabled, then reload Canvas.
5. Open a Sydney Canvas unit’s Recorded Lectures class list.
6. Open Lecture transcripts, select Scan this unit, then Download TXT + VTT.

Keep the source unit open while downloading. Open folder reveals a saved transcript in Finder after the first successful save.

Both formats save under `EchoVideo Transcripts/<unit> [section suffix]/` inside Chrome’s configured download location, normally Downloads. For unattended saving, turn off Chrome Settings → Downloads → Ask where to save each file before downloading. This preference affects all Chrome downloads.

This is an unpacked extension with manual updates. It supports University of Sydney Canvas and Australian EchoVideo hosts, tested in Chrome on macOS. Availability depends on EchoVideo; review scan warnings.
